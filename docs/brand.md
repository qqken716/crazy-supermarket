# 满筐小铺品牌说明

## 名称

- 正式名称：满筐小铺
- 拼音标识：Mankuang Shop
- 命名含义：“满筐”对应采集、生产和补货形成的满载反馈，“小铺”强调轻松、亲切的模拟经营体验。

公开网页检索未发现明确的同名游戏或品牌结果，但公开搜索不等于商标核验。
正式发布前仍应在国家知识产权局商标查询系统中检查文字和图形近似情况，
并在微信公众平台确认名称可注册。游戏软件和在线游戏服务通常需要重点核查
第 9 类和第 41 类，具体类别应由商标专业人士结合实际业务确认。

## Logo

图形由购物筐、店铺遮棚、苹果、番茄、鸡蛋、牛奶和金币组成，直接对应游戏的
采集、生产、补货和结账循环。图形不使用现实商超名称、品牌字母、知名角色或
现有连锁商超的标志性构图。

主色：

- 阳光黄：`#FFD314`
- 珊瑚红：`#FF5B45`
- 鲜叶绿：`#53B934`
- 天空蓝：`#72CFF2`
- 可可棕：`#4A2518`

`package.json` 包名和本地存档键继续保留旧内部代号，避免已有开发环境和玩家
存档因品牌改名失效。

## 生成说明

图形标通过 OpenAI 内置图像生成工具原创生成，未提供或模仿第三方参考图。
中文字标使用系统黑体本地排版，避免生成式模型产生错字。各尺寸可通过以下命令
重新导出：

```bash
python3 scripts/build-brand-assets.py
```

脚本需要 Pillow，并使用 macOS 自带的 `STHeiti Medium` 字体。

## 发布前核查

1. 在[国家知识产权局](https://www.cnipa.gov.cn/)商标查询入口检索“满筐小铺”、
   “满筐”和近似读音。
2. 对图形标进行图形近似检索，重点检查购物筐、店铺遮棚组合。
3. 在微信公众平台提交名称前确认没有同主体限制、平台占用或投诉风险。
4. 保存源图、生成日期和项目提交记录，作为原创过程材料。

以上是设计和初步排查说明，不构成法律意见或商标注册成功保证。
